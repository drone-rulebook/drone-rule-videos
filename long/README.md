# 長尺の解説動画（横長・約10分）の作り方（Claude 向け）

持ち主はコードを書きません。説明は日本語で短く、作業は Claude が進めます。

## しくみ
- `long/<ID>.json`（台本）を置いて push すると、Actions「長尺の解説動画をつくる」（`.github/workflows/long.yml`）が `long.py` で動画にし、`long_videos/<ID>.mp4`・`_thumb.png`・`_desc.txt`・`_info.json` を入れます（約10分）。
- 台本か `long.py` が動画より新しいときだけ作り直します。
- 声は VOICEVOX のずんだもん（声だけ。キャラクターの絵は描かない・使わない）。画面と説明欄には「音声：VOICEVOX:ずんだもん」を必ず出す。
- 文言は「教則第5版対応」。「ずんだもんが解説」「非公式の解説」は使わない。

## 台本の決まり
- ID は L001 から順に。1本＝1テーマ・10問（2択の「これ違反？」を2〜3問まぜる）。できあがりは9〜11分。
- 根拠は国土交通省『無人航空機の飛行の安全に関する教則』第5版だけ。各問に `basis`（章・節の番号）を書く。確かめていない数字や規則は書かない。「9割が間違える」のような根拠のない数字も書かない。
- 有料の note の本文はここ（公開の置き場）に写さない。
- 形は `long/L001.json` と同じ：
  - `title`（YouTube の題名。【ドローン国家資格】…ひっかけ10問【二等学科・教則第5版対応】）、`theme`、`thumb`（2行。改行は `\n`、色を変える語は `*` で囲む）、`intro`・`outro`（ずんだもんの話し言葉「〜なのだ」）
  - `questions` の1件：`q`（問題）、`choices`（3つか2つ）、`answer`（A/B/C）、`explain`（読み上げる文。5〜8文）、`points`（画面に出す要点 1〜3。1つ目は「まとめ」にも出る）、`basis`、`chapter`（目次の名前。答えを書かず論点だけ）
  - 正解は A・B・C にばらけさせる。同じ論点を続けない。
- 作った人とは別のサブエージェント（チェック係）が、1問ずつ教則第5版の本文と照らして点検し、合格してから push する（不合格は直して再点検、2回落ちたら差し替え）。
- 先に `python long.py long/<ID>.json /tmp/x.mp4 --no-voice` で通るか確かめ、何こまか画像を見て、文字がはみ出していないか確かめる。

## 出したテーマ
- L001 飛ばしてはいけない空域（飛行禁止空域・DID・150m・空港・緊急用務空域・小型無人機等飛行禁止法）

## 次の候補（重ならないように）
- 承認が要る飛び方（夜間・目視外・30m・催し・危険物・物件投下）
- 機体登録とリモートID
- 技能証明・機体認証とカテゴリー（I・II・III）
- 飛行計画の通報・飛行日誌・事故の報告
- 気象（風・気温・雷・気圧）
- バッテリーと機体の点検
