# サイト「ドローンのルール帳」のしくみ

二等無人航空機操縦士（ドローン国家資格）の学科の「ひっかけ問題」を、スマホで解ける無料サイトです。
動画と同じ「動画台本」シートから、毎日自動で作り直して GitHub Pages に公開します。

公開先（予定）：https://drone-rulebook.github.io/drone-rule-videos/

## 毎日の流れ

1. 毎日 **19時37分（日本時間）** に、GitHub Actions の「サイトをつくる」が動きます（18時台のショート公開の後）。
2. 公開した「動画台本」シート（`config.json` の `csv_url`）を読みます。
3. 見本のCSVでサイトの作りを確かめてから（`tests/test_site.py`）、本物のシートでサイトを作り、GitHub Pages に公開します。
4. シートが読めなかったときや、使える問題が1つも無いときは、**公開中のサイトはそのまま**残ります（Actions の画面に赤い×が出ます）。

`site/` `fonts/` を変えて main に置いたときにも、自動で1回作り直します。手で動かすときは「Actions」→「サイトをつくる」→「Run workflow」。

## シートのどの行を使うか

- 「状態」が **待ち** か **投稿済み** の行だけを使います。**停止** の行は使いません。
- 「メモ」に **限定公開** と書いた行（試しの投稿）は使いません。
- 問題・3択・正解（A〜C）・ひっかけ・タイトルのどれかが空の行は使いません。
- 「問題ID」が同じ行が複数あるときは1つにします（動画URLがある行 → 投稿済みの行 → 公開予定日が早い行 の順に選びます）。
- 「問題ID」は英数字・`-`・`_` だけにしてください（ページのURLになります。例：`Q001` → `/q/Q001/`）。
- `*` で囲んだ所は強調（黄色のマーカー）になります。
- 「動画URL」は YouTube のURL（`https://www.youtube.com/…` か `https://youtu.be/…`）だけをリンクにします。無いときは公開予定日を出します。

問題・答え・ひっかけの文は、シートの文をそのまま使います。サイトのプログラムは問題の中身を書きません。

## ページ

| ページ | 中身 |
| --- | --- |
| トップ `/` | サイトの説明、「10問ミニ模試をはじめる」、新しい問題、X と note へのリンク |
| ミニ模試 `/quiz/` | 最大10問をまぜて出題 → その場で正誤とひっかけ → 点数・まちがえた問題・Xでシェア・note の案内 |
| 1問1ページ `/q/問題ID/` | 問題・3択・「正解を見る」・ひっかけ・ショート動画・ほかの問題・note の案内 |
| 問題の一覧 `/q/` | すべての問題 |

ほかに、共有したときの画像（`/og/…png`、1200×630）、`sitemap.xml`、`robots.txt`、`404.html` を作ります。
共有画像には答えを入れません。フォント（`fonts/`）に無い文字がある問題は、サイト共通の画像を使います。

## 守っていること

- 入力欄・クッキー・アクセス解析・広告はありません。外部のスクリプトやフォントは読み込みません（端末の文字を使います）。
- 「Xでシェア」は、本人がボタンを押して X の投稿画面を開く形です（サイトからは何も送りません）。
- ページの足もとに「国土交通省『無人航空機の飛行の安全に関する教則』（第5版）にもとづいて作成。国の機関とは関係のない非公式の学習サイトです」と最終更新日を出します。

## 文言・色・リンクを変えるとき

`site/site.json` だけを書きかえます（別のテーマのサイトにも使い回せます）。

- `site_name`：サイト名
- `site_url`：公開先のURL（Actions では GitHub Pages のURLが自動で入ります）
- `texts`：画面の文言。`{n}` `{total}` `{date}` などは自動で数字や日付に置きかわります
- `links`：X・note・シェア先
- `colors`：画面の色、`og`：共有画像の色
- `quiz_size`：ミニ模試の問題数、`latest_count`：トップに出す新しい問題の数、`others_count`：「ほかの問題」の数

## ファイル

| ファイル | 役目 |
| --- | --- |
| `site/build.py` | シートを読んでサイトを作る |
| `site/og.py` | 共有画像を作る（Pillow と `fonts/`） |
| `site/site.json` | 文言・色・リンク |
| `tests/sample.csv` | 見本の台本（本物と同じ列。中身は確認用の見本） |
| `tests/test_site.py` | 見本でサイトを作り、決まりどおりか確かめる |
| `.github/workflows/site.yml` | 毎日19時37分と、部品を変えたときに作り直して公開する |

手元で試すとき：

```
pip install pillow
python site/build.py --csv tests/sample.csv --today 2026-10-16 --out _site
python tests/test_site.py
```

## 注意

- 動画づくり（`render.py`・`music.py`・`config.json`・`.github/workflows/render.yml`）には手を入れていません。
- `site/` を変えて main に置くと、動画の「動画をつくる」も1回動きます（いつもどおり近い日の動画を作るだけで、害はありません）。

## 最初に1回だけやること（GitHub Pages の設定）

1. GitHub でこの置き場を開き、「Settings」→ 左の「Pages」。
2. 「Build and deployment」の「Source」を **GitHub Actions** にする。
3. 「Actions」→「サイトをつくる」→「Run workflow」で1回動かす。緑の✓が出たら、上の公開先URLで見られます。
