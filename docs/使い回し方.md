# 使い回し方：別のテーマでチャンネルを作るとき

この仕組みは「台本シート（CSV）→ 3択クイズの縦型ショート」を毎日作るものです。
問題の中身（ドローン以外の資格・語学・雑学など）を変えても、そのまま使えます。

## 変える所（プログラムは触らなくてよい所）

### 1. 設定ファイルを写す：`themes/`
`themes/drone.json` を写して、新しい名前（例 `themes/eiken.json`）にします。中身の意味：

| 項目 | 何か | 例 |
|---|---|---|
| チャンネル名 | 締めの画面の上に出る名前 | ドローンのルール帳 |
| 見た目の版 | 見た目を変えたら1つ増やす数。増やすと、まだ公開していない動画（公開予定日が今日以降で「待ち」）が新しい見た目で作り直される | 2 |
| 画質 | `1080x1920` か `720x1280` | 1080x1920 |
| 文言 → ラベル | 左上の小さな見出し | 二等学科 ひっかけ問題 |
| 文言 → 正解 | 「正解は B」の「正解は」 | 正解は |
| 文言 → ひっかけ見出し | ひっかけ欄に「〇〇：」が無いときの見出し | ひっかけ |
| 文言 → 締め1〜3 | 最後の画面の3行（根拠のない数字は書かない） | 毎日1問 ／ ひっかけ対策 ／ チャンネル登録で毎日届きます |
| 型の選び方 → 型 | 使う見た目の型と順番（モーション・黒板・ノート から選ぶ） | ["モーション", "黒板", "ノート"] |
| 型の選び方 → 方法 | 「順番」＝台本IDの数字で日替わり（v004→黒板、v005→ノート、v006→モーション…）。「固定」＝型の最初の1つだけ | 順番 |
| BGM | BGM を入れるか（true／false） | true |
| 声 → 使う | 読み上げの声を入れるか（はじめは false） | false |
| 声 → 読み替え | 読み上げで読み方を直したい言葉（小文字の単位は数字のすぐ後ろだけ） | "m": "メートル" |
| 色 | 型ごとの色（#RRGGBB）。テーマに合わせて変える | "強調": "#FFC400" |

台本に「型」という列を足して、その行だけ型を決めることもできます（空なら日替わり）。

### 2. どの設定ファイルを使うか：`config.json`
`config.json` に `"theme": "eiken"` を1行足します（無ければ `drone` を使います）。
**`csv_url`・`days_ahead`・`keep_days` はほかの仕組みも読んでいるので、新しいチャンネルでは、この置き場ごと写して（別の置き場にして）から変えてください。**

### 3. 台本シート
列は同じにします：台本ID・公開予定日・問題ID・タイトル・問題1行目・問題2行目・選択肢A・選択肢B・選択肢C・正解（A〜C）・ひっかけ・状態（待ち／投稿済み／停止）・動画URL・投稿日時・メモ。
- `*` で囲んだ所が強調されます（例：`150mは*どこから*測る？`）。
- ひっかけ欄は「ひっかけ：〜」と書くと、「ひっかけ」が見出しになります。
- 長い文は自動で折り返し・縮小します。問題は3行、選択肢は2行、ひっかけは3行までが目安です。

### 4. フォントに無い文字
`fonts/` のフォントは、よく使う漢字だけに減らしてあります（`fonts/chars.txt` が入っている文字の一覧）。
台本に入っていない文字があると、その台本は作らずに `status.json` の「見送った台本」に文字といっしょに出ます。
新しいテーマで専門の漢字が多いときは、フォントを作り直す必要があります（プログラムが分かる人に頼む）。

## 確かめ方（プログラムが分かる人向け）
- `python render.py --samples` … 型ごとの見本を `samples/` に作る（mp4 と見せ場を並べた画像）
- `python render.py --csv tests/見本台本.csv 出力先 --sheets` … 見本の台本の全行を作る（`--sheets` で、YouTube の文字やボタンが重なる所を赤く示した静止画も作る）
- `python render.py --sample out.mp4 --style 黒板` … 1本だけ作る

## しくみの地図（プログラムが分かる人向け）
| ファイル | 役目 |
|---|---|
| `render.py` | 台本を読んで、作る・作り直す・消すを決める。書き出し（ffmpeg）。`status.json` を書く |
| `styles/` | 見た目の型。`base.py`＝流れ（秒）と置き場所、`motion.py`・`chalk.py`・`notebook.py`＝3つの型、`hand.py`＝手書き2型の共通部分 |
| `drawkit.py` | 文字・図形・手書き線・質感の道具。大事な文字を置いてよい範囲（`SAFE`） |
| `audio.py` | 効果音（波形から作る）と、BGM・声を混ぜる |
| `music.py` | BGM（プログラムで作る曲） |
| `voice.py` | 読み上げ（Open JTalk）。部品が無ければ声なしで作る |

型を足すときは `styles/` に `Look` を受けつぐ型を作り、`styles/__init__.py` に登録し、`themes/*.json` の「色」と「型」に名前を足します。流れ（問題→3択→カウントダウン→正解→ひっかけ→締め）と秒は `styles/base.py` で全部の型に共通です。
