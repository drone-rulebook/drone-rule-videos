# ドローンのルール帳：動画の置き場

二等学科の「ひっかけ問題」を、毎日1本、縦型のショート動画（約11〜14秒・1080×1920）にして置いておく場所です。

## しくみ

1. スプレッドシートの「動画台本」シート（ウェブに公開したCSV）を、GitHub Actions が毎日2回読みます（日本時間 1時17分・13時17分）。
2. 公開予定日が近い「待ち」の台本を、`render.py` で動画にして `videos/台本ID.mp4` に置きます。
3. スプレッドシートのスクリプトが、決まった時刻にこの動画を取りに来て、YouTube に投稿します。

- 動画の流れ（見た目の版5）：1こま目から問題の全文（見出し・番号・ドローンの絵つき）→ 3択（選択肢C が空の台本は2択）→ カウントダウン（「どれ？コメントで答えてね」）→ 正解 → ひっかけの説明 →（締めの声を使う動画だけ「毎日18時に1問」の帯と声）→ 1こま目と同じ「問題だけ」の画面に戻る（くり返し再生がつながるように、締めの画面は置かない）。
- 問題の読み上げが長いときは、読み終わるまでカウントダウンを待つ（最大1.2秒。2択は2.6秒）。
- 締めの声は `themes/drone.json` の「締めの声を使う」（偶数・奇数・全部・なし）で、台本IDの数字の偶数・奇数ごとに入れる・入れないを分けられる（登録とくり返し再生を比べるため）。どの動画に入れたかは `status.json` の「締めの声」に残る。
- 見た目は3種類（モーション・黒板・ノート）で、台本IDで日替わりになります。見本は `samples/` にあります。
- 絵・動き・文字・効果音・BGM は、すべてプログラムで作っています（画像や音の素材、画像・動画の生成AIは使っていません）。
- チャンネル名・文言・色・型の選び方は `themes/drone.json` にまとめてあります。別のテーマで使うときは `docs/使い回し方.md`。
- 見た目を変えて `themes/drone.json` の「見た目の版」を増やすと、まだ公開していない動画（公開予定日が今日以降の「待ち」）を新しい見た目で作り直します。作り直しに失敗したときは、古い動画をそのまま残します。
- 読み上げの声は付けられますが、はじめは切ってあります（`themes/drone.json` の「声」→「使う」）。
- 公開予定日から10日たった動画は、置き場を軽く保つため自動で消します。
- 最後に動いたときの結果は `status.json` に残ります（作った動画・作り直した動画・失敗・エラーの内容、使った見た目の型）。
- `render.py` や設定を変えて置いたときにも、自動で1回動きます。
- 手で動かすときは、「Actions」→「動画をつくる」→「Run workflow」。

## フォント・声のクレジット

`fonts/` の Noto Sans CJK JP は、動画に必要な文字だけに減らした版です（SIL Open Font License 1.1。`fonts/OFL.txt`）。

声を使うときは、Open JTalk（名古屋工業大学・修正BSDライセンス）と、声のデータ HTS Voice "NITECH-JP-ATR503-M001"（名古屋工業大学・CC BY 3.0）を使います。CC BY 3.0 の決まりにより、ひっかけの説明のあいだ、画面の下にクレジットを小さく出します（VOICEVOX のときも同じ。説明欄にも書く）。
