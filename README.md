# ドローンのルール帳：動画の置き場

二等学科の「ひっかけ問題」を、毎日1本、縦型のショート動画（約13秒）にして置いておく場所です。

## しくみ

1. スプレッドシートの「動画台本」シート（ウェブに公開したCSV）を、GitHub Actions が毎日2回読みます（日本時間 1時17分・13時17分）。
2. 公開予定日が近い「待ち」の台本を、`render.py` で動画にして `videos/台本ID.mp4` に置きます。
3. スプレッドシートのスクリプトが、決まった時刻にこの動画を取りに来て、YouTube に投稿します。

- 絵・動き・文字・効果音は、すべてプログラムで作っています（素材は使っていません）。
- 公開予定日から10日たった動画は、置き場を軽く保つため自動で消します。
- 最後に動いたときの結果は `status.json` に残ります（作った動画・失敗・エラーの内容）。
- `render.py` や `config.json` を変えて置いたときにも、自動で1回動きます。
- 手で動かすときは、「Actions」→「動画をつくる」→「Run workflow」。

## フォント

`fonts/` の Noto Sans CJK JP は、動画に必要な文字だけに減らした版です（SIL Open Font License 1.1。`fonts/OFL.txt`）。
